# Device 参数台账

最后核对日期：2026-07-15

本文件记录工程中每个 Device 的实物型号、部署归属、连接方式、配置参数、
软件默认值和安全限制。记录时使用以下状态：

- **代码默认**：当前源码中的默认值，只说明软件行为，不代表实物已经这样配置。
- **已确认**：由实物、原理图、数据手册或用户确认的信息。
- **待确认**：当前没有可靠来源，禁止根据模块名称或常见接法猜测。

参数来源优先级为：实物丝印/原理图与 BOM、厂家数据手册、用户确认、当前源码。
同一类 Device 如果在不同产品中使用不同实物，必须分成多个“设备实例”记录。

5. Key：数量、所属产品、GPIO、消抖/长按/双击时间；器件本身按普通按键处理。
6. Vision：UART 实例、波特率、电平、帧格式和刷新率；设备型号不再询问。
7. QD4310：数量和 ID、CAN 波特率、产品允许电流、反馈周期/超时及安装方向。
8. BMI088/JY61P：不再询问模块型号；只在需要接入 BSP 时记录 SPI/UART、安装轴、
   采样和校准参数。
9. ICM-45686：型号和板载 SPI1 已确认，只需确认它相对车体的安装轴映射和实际
   零偏校准参数；不再询问模块型号。
