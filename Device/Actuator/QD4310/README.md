# QD4310

本驱动依据《QD4310 使用手册》V2.3（2026-04-20）实现 CAN 控制。QD4310 是集成
FOC 驱动器和 15 bit 磁编码器的无刷伺服电机；Device 负责协议编解码、本地命令限幅
和反馈状态，不负责 CAN 引脚、MCAN 寄存器、FreeRTOS 调度或云台控制算法。

## 实物安全边界

- 供电 `7..26 V`，额定/峰值电流 `1/2 A`。
- 额定/峰值转速 `500/800 RPM`，额定/峰值扭矩 `0.2/0.3 N·m`。
- 转矩常数 `0.27 N·m/A`；15 bit 编码器等效 32768 线，控制精度 `0.0109°`。
- 首次使能前必须完成基础校准；校准时电机失能、尽量空载，推荐 `8..20 V` 且
  电源能力大于 `2 A`。
- 二进制协议的电流编码满量程是 `±10 A`，不是电机允许电流。默认配置把本地
  命令限制为额定 `1 A`，用户配置也不允许超过物理峰值 `2 A`。
- 默认速度命令限制为额定 `500 RPM`，用户配置不允许超过物理峰值 `800 RPM`。

## CAN 协议

- 固定 `1 Mbps`、11-bit 标准 Classic CAN；同一总线最多 8 台电机。
- ID 有效范围 `0x00..0x0F`，同一总线必须唯一。
- 控制帧：ID `0x400 + motor_id`，DLC 3，内容为指令、控制量低字节、高字节。
- 反馈帧：ID `0x500 + motor_id`，DLC 8，内容为状态、预留、电流、速度和角度。
- 每个匹配自身 ID 的控制帧触发一个反馈帧；`NOP` 可只请求反馈。

| 命令 | 值 | 控制量 |
|---|---:|---|
| NOP | `0x00` | 忽略，只请求反馈 |
| Enable | `0x01` | 忽略 |
| Disable | `0x02` | 忽略 |
| Current | `0x03` | `int16`，协议满量程 `±10 A` |
| Speed | `0x04` | `int16`，协议满量程 `±1000 RPM` |
| Angle | `0x05` | `uint16`，`0..2π rad` |
| LowSpeed | `0x06` | 与 Speed 相同；低于 5 RPM 时推荐，发送频率低于 50 Hz |
| StepAngle | `0x07` | `int16`，`-2π..+2π rad` |

实例初始化时会检查 CAN 标称速率必须为 1 Mbps，并默认禁止所有运动命令。只有
Enable 帧成功提交后才开放运动命令；Disable 会先在本地锁定，再尝试发送失能帧。
多个实例共用 CAN 时，接收方读取一帧后可交给每个实例按反馈 ID 匹配。

## 其他通信方式

手册还定义了 USB 虚拟串口和 3.3 V UART。UART 默认 115200 bps，控制/反馈包分别
为 5/10 字节，CRC8 参数为 poly `0x07`、init/xorout `0x00`、不反转。UART 必须严格
一发一收；硬件 V6.1 及以上才支持一主多从。当前目录只实现 CAN，UART 尚未实现。
手册 V2.3 中 PWM 仍标记为开发中，不作为可用控制接口。
